# Sommelier Spark — Combined Glossary

This glossary consolidates all terms from across the Sommelier Spark ecosystem.

---

## Wine Terms

| Term | Definition |
|------|------------|
| **Acidity** | The tart, crisp quality in wine that makes your mouth water |
| **Appellation** | A legally defined wine-producing region |
| **Aroma** | Scents derived from the grape variety itself |
| **Body** | The weight and fullness of wine in your mouth (light, medium, full) |
| **Bouquet** | Scents that develop from aging and winemaking |
| **Dry** | A wine with little to no residual sugar |
| **Finish** | The taste that lingers after you swallow |
| **Nose** | The overall smell of a wine, including aroma and bouquet |
| **Palate** | The taste and texture of wine in your mouth |
| **Tannins** | Compounds that create a drying sensation, mainly in red wines |
| **Terroir** | How a place's climate, soil, and geography affect wine character |
| **Varietal** | A wine made primarily from one grape variety |
| **Vintage** | The year the grapes were harvested |

---

## App Terms

| Term | Definition |
|------|------------|
| **Certification** | Achievement level (Bronze, Silver, Gold) earned by completing requirements |
| **Dashboard** | Your home page showing progress and quick actions |
| **Lesson** | A single unit of learning content within a module |
| **Level** | Quiz difficulty tier (Level 1/Bronze = easiest, Level 3/Gold = hardest) |
| **Module** | A course containing related lessons on a wine topic |
| **Progress** | Your completion status across wines, modules, quizzes, and scenarios |
| **Scenario** | Interactive simulation of a real-world service situation |
| **Studied** | A wine you've reviewed and marked as learned |
| **Tier** | Difficulty level for content (Bronze, Silver, Gold) |

---

## Certification Terms

| Term | Definition |
|------|------------|
| **Bronze** | Foundation-level certification requiring 70%+ average quiz scores |
| **Gold** | Expert-level certification requiring 80%+ average quiz scores |
| **Not Certified** | User hasn't completed minimum requirements for any certification |
| **Silver** | Intermediate certification requiring 75%+ average quiz scores |

---

## Administrative Terms

| Term | Definition |
|------|------------|
| **Admin Portal** | The management interface accessible to administrator roles |
| **Brand** | A business unit or concept within an organisation |
| **Brand Admin** | Administrator who manages a specific brand and its locations |
| **Location** | A physical venue where staff work |
| **Location Admin** | Administrator who manages a specific location |
| **Organisation** | Top-level company or group using Sommelier Spark |
| **Org Admin** | Administrator who manages an entire organisation |
| **Role** | The permission level assigned to a user |
| **Scope** | The visibility level of content (Global, Organisation, Brand, Location) |
| **Staff** | Regular users who consume training content |
| **Super Admin** | Platform administrator with full system access |
| **Suspension** | Temporarily disabling access without deleting data |
| **Tenant** | The organisational context a user belongs to |

---

## Content Terms

| Term | Definition |
|------|------------|
| **Global Content** | Content visible to all users across all organisations |
| **Location Content** | Content visible only to users at a specific location |
| **Organisation Content** | Content visible to all users within an organisation |
| **Quiz** | An assessment with questions testing knowledge |
| **Wine** | A wine entry in the catalog with study materials |

---

## Status Terms

| Term | Definition |
|------|------------|
| **Active** | Account or content is accessible and functioning |
| **Completed** | A module, quiz, or scenario that has been finished |
| **Deleted** | Permanently removed (cannot be recovered) |
| **In Progress** | Content that has been started but not completed |
| **Inactive** | User account exists but cannot log in |
| **Locked** | Content not yet available (requirements not met) |
| **Suspended** | Temporarily blocked; can be restored |
| **Unlocked** | Content available for access |

---

## Developer Terms

| Term | Definition |
|------|------------|
| **Capacitor** | Framework for wrapping web apps as native iOS/Android apps |
| **localStorage** | Browser storage used by iOS app for offline data |
| **Next.js** | React framework used for both web and iOS projects |
| **PostgreSQL** | Database used by the web application |
| **Prisma** | ORM used by the web application for database access |
| **Static Export** | Next.js build mode used for iOS (no server required) |
| **Simulator** | Xcode's iOS device emulator for testing |
